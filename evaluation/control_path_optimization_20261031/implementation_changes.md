# 隔离实现与固定协议

生产模块、旧实验及安装的 SGLang 均未修改。runner/control/bridge/observation/protocol/device_entry 从原 P0 包复制；原始哈希见 original_code_manifest.json。改动仅为新包入口、子进程可切换读取函数以及附加诊断记录。

batched_payload.py 在同一次观察内按组件批量复制 Recurrent 槽位，FA 按原层顺序分组复制（目标上限64 MiB，单层超过时保留该层整体）。按原槽位/层/组件顺序产生完全相同SHA；无跨调用缓存，无删除校验、驱逐或同步窗口。暂存GPU张量为额外工作区，不声称零开销。性能版与原版保留全部原审计、日志、时间边界。验证版额外逐调用计算旧摘要对照，不计入性能样本。

执行顺序预先固定：先一个批量版FS正确性Smoke；随后五对原版/批量版FS，奇数轮原版先、偶数轮批量版先。若五轮控制配对差中位数下降且无正确性失败，继续批量版三策略五轮，沿用原P0三策略ROUND_ORDER。所有臂均新Engine；不得将Smoke计入性能。GPU固定原GPU0 UUID，任何占用、磁盘不足20GiB、正确性失败即停，不自动切卡或重试。

控制时钟仍T0–T3，完整周期仍T0–T4（包含形状预热、日志尾段、请求与间隙），直接来自原runner；不移动审计到其他时间窗口，不扣除估计开销。每臂原始Cold、Native Match/COW、FA和组件保护、独立Oracle、T0–T4整数恒等式继续执行。保留负结果。
