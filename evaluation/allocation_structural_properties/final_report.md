# FlowState 分配结构性质审计（Phase T1）

本报告仅进行理论推导和冻结证据复核。没有运行策略比较、GPU、Engine、Docker 或回放，没有实现新求解器，没有修改生产算法、模型、兼容关系及历史结果。

结论标签：**PROVED** 表示给出严格证明；**CONDITIONAL** 表示结论仅在列明的额外假设下成立；**OBSERVED** 表示冻结实例观察；**OPEN** 表示现有证据尚未解决。条件性定理的证明可以完整成立，但其条件在实际 Runtime 中是否成立是另一个问题。

核心结论：固定非负收益矩阵具有标准单调次模结构；正收益支持可分时可精确化简；预算饱和只保证最优解饱和，不保证逐步 Greedy 饱和。纯 Token 前缀树及深度支配条件下，可以通过带最近已选祖先的树形动态规划精确求解。后者是本轮的条件性结构推导，不是已经实现或验证的新算法，也不主张数学新颖性。

## 1. 数学假设与实现对应

### 1.1 固定快照合同（CONDITIONAL）

有限集合 P、C、准入边、整数位置 L_c、目标 T_p 和成本函数均固定。所有准入边满足 0≤L_c≤T_p；各候选等大小，唯一联合约束为 |S|≤K，K 为非负整数。对固定 T，Phi(G,T) 随 G 非减且有限。定义空集前沿为 0：

\[
E_p(S)=\max(\{L_c:c\in S,c\preceq p\}\cup\{0\}),\quad
b_{p,c}=\begin{cases}\Phi(T_p,T_p)-\Phi(T_p-L_c,T_p),&c\preceq p,\\0,&\text{其他}.\end{cases}
\]

因此 b≥0，最深兼容候选取得最大单请求收益，直接得到

\[
J(S)=\sum_p\Phi(T_p-E_p(S),T_p),\quad
F(S)=J(\varnothing)-J(S)=\sum_p\max(\{b_{p,c}:c\in S\}\cup\{0\}).
\]

这是模型恒等式，不证明 Runtime 的恢复起点仅由 S 决定。若存在未纳入模型的可恢复基础状态、执行途中物化/失效、在线目标改变或配置冲突，必须先建立相应执行合同；本轮不改写原目标来吸收这些问题。逻辑基数也不等于实际 HBM 容量。

源码：`flowstate/recovery_model.py:38–103`；`flowstate/optimizer.py:34–145`。B4-C 的 `evaluation/strict_compatibility_b4c/evaluate.py:26–29` 用独立矩阵成本接口复用生产选择过程，避免旧 Workflow 谓词过滤已准入的跨 Workflow 边；`evaluate.py:31–88` 读取冻结状态及结果计算口径。本轮只读取该代码及已有结果，不调用它重新评估。

### 1.2 冻结 Phi 的单调性（PROVED，模型推论）

依据 `evaluation/FORMAL_RECOVERY_MODEL.md` 和 `flowstate/recovery_model.py:38–103`，令 g=G/1024、t=T/1024：

\[
\Phi=37.828150g+0.345974143gt-0.156201917g^2.
\]

在正式域 0≤g≤t≤128，

\[
\partial\Phi/\partial g=37.828150+0.345974143t-0.312403834g
\ge37.828150+0.033570309t>0.
\]

故该模型严格单调，Phi(0,T)=0。所有深度支配和非负收益结论在此域成立；不把经验拟合模型在域外的代数延拓当作已校准的恢复性能。

## 2. 正式性质及证明

### 2.1 T1：单调性、次模性与 Greedy 保证（PROVED，标准性质）

记 u_p(S)=max({b_pc:c∈S}∪{0})。F(∅)=0。若 A⊆B，则 u_p(A)≤u_p(B)，所以 F(A)≤F(B)。对 c∉B，

\[
\Delta(c\mid S)=\sum_p\max(0,b_{p,c}-u_p(S)).
\]

逐项使用 u_p(A)≤u_p(B)，得 Δ(c|A)≥Δ(c|B)，即次模性。此证明不要求兼容图可分、树形、无共享，也不要求 Phi 可微；只需固定的非负 max-benefit 表达。Phi 单调性用于证明该表达与原 J/E 定义等价。

令 O 为 |O|≤K 的最优集合，S_i 为精确最大边际 Greedy 的前 i 步。由单调性、次模性及 |O\S_i|≤K：

\[
F(O)-F(S_i)\le\sum_{c\in O\setminus S_i}\Delta(c\mid S_i)
\le K\max_{c\notin S_i}\Delta(c\mid S_i).
\]

故残差每步最多乘以 1−1/K，K≥1 时

\[
F(S_K)\ge\gamma_KF(O),\qquad
\gamma_K=1-(1-1/K)^K\ge1-1/e.
\]

若提前出现最大边际为零，则所有剩余项的总增益也为零，当前解已全局最优。K=0 返回空集；K≥|C| 时正边际停止或选完全部候选均达到 F(C)。精确同分选任何候选均不影响上述保证。

上述是经典基数约束单调次模 Greedy 定理，不是 FlowState 的新数学贡献。参考 Nemhauser、Wolsey、Fisher（1978），[原论文](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf)，[DOI](https://doi.org/10.1007/BF01588971)。这里给出完整专门化证明，以明确模型适用条件。

转为成本形式仅得到

\[
J(S_K)\le(1-\gamma_K)J(\varnothing)+\gamma_KJ(O).
\]

这不是 J 的乘法近似比；当 J(O)=0 时，Greedy 仍可有正成本。也不是物理内存利用率、GPU TTFT 或控制开销后端到端延迟的近似保证。

**数值实现边界（CONDITIONAL）：** `optimizer.py:14,90–128` 使用 1e−9 ms 同分容差、ID 破同分、非正收益停止。精确实数定理不能原封不动声称为浮点程序的机器级证明。若每步所选边际距真实最大值至多 δ，则同样递推给出 F(S_K)≥γ_KF(O)−Kδ；提前停止也需对应的残差界。在排序扫描和精确算术下，同分容差可纳入 δ，但本报告没有证明浮点累积误差的全局界。冻结实例的大幅失败不能解释为 1e−9 同分误差。

**不直接适用的变化：** 集合改变兼容性/目标/Phi，选择引起额外互补收益，恢复必须联合多个不完整组件，或选择期间状态改变，均可能破坏固定 max 表达。非等大小、多个资源约束、保护集合约束等即使仍保留次模性，也不再是本证明的纯基数 Greedy 可行域和保证。

### 2.2 T2：正收益支持可分的精确化简（PROVED，模型推论）

**命题。** 若每个候选的正收益支持 P_c={p:b_pc>0} 大小至多 1，且满足等大小、纯基数、无其他联合约束，则以下方法精确最优：对每个 p 找到正收益最大项 c_p，记 a_p=b_{p,c_p}；选 a_p 最大的至多 K 个有效 Pending 的代表项。

**证明。** 将正收益候选按其唯一受益 Pending 分成互不相交的 C_p。任意可行 S 对某个 p 的贡献不超过 a_p，且最多为 |S|≤K 个不同 p 提供正贡献。故 F(S) 不超过最大的 min(K,m) 个正 a_p 之和，m 是有正收益的 Pending 数。每个入选 p 取 c_p，由 C_p 互不相交，这些代表是不同候选，占用恰 min(K,m) 个名额，并达到上述上界。证毕。

**边界。** C 或 P 为空、所有收益零、K=0 时最优值零；K>m 时选 m 项即可，剩余预算无需填满。组内或组间同分允许多个最优解，ID 破同分只确定代表，不增加收益；一致的精确 tie-breaking 才可能保证相同集合。零收益兼容边不破坏正收益分组。此条件是充分条件，不是精确可解或策略持平的必要条件。

**与 Greedy、PCB、LDR 的关系。** 精确 Greedy 每次取某个未满足组的最大值，随后该组其他项边际归零，因此也实现上述化简。冻结 PCB（`evaluation/p1_strong_baseline_validation/pcb.py:5–22`）按每请求最大恢复收益推荐、全局排序和 ID 去重，在这些条件下实现同一精确解。LDR（同目录 `ldr.py:4–17`）在单请求内取最深项是有效支配消除，但跨请求按深度排序只有在 a_p 的排序与代表深度一致时才精确。例如所有 T 相同且使用同一单调 Phi 是充分条件；不同 T 下不作此保证。某预算恰好包含全部正组也是充分的退化情形。

存在共享时，C_p 不再是互不相交的选择单元，一个候选可同时贡献多个 p，以上可达上界证明不能照搬。反过来，有共享不意味着简单策略必败：预算足够且实际选中了全部最佳前沿实现者、共享项恰为共同最佳项、或各评分在当前路径同序，都可能产生持平。

### 2.3 T3：预算饱和（PROVED，模型推论）

令 E*_p=E_p(C)，定义

\[
K_{\min}=\min\{|S|:S\subseteq C,\ \forall p,E_p(S)=E_p^*\}.
\]

C 自身可行，故该最小值存在；全部 E*=0 时 K_min=0。对任意 S⊆C，由 E(S)≤E* 和 Phi 非减，J(S)≥J(C)。当 K≥K_min 时，定义中的最小见证集合可行且成本为 J(C)，因此 J(OPT)=J(C)。证毕。

这不保证任意策略找到该见证集合，不保证 Greedy 不浪费早期名额，也不保证 E*=T。若某请求最深候选仍浅于目标，则即使保留全体候选仍有不可消除的 G。反向“成本饱和要求前沿饱和”在仅非减、有平台的 Phi 下不成立；对本轮严格单调 Phi 则成立，故其最小成本饱和预算与 K_min 一致。K_min 始终是逻辑前沿覆盖指标，不是 pool slot 数。

### 3.5 候选排序与位置项的证据边界

**PROVED：** 记 singleton a_c=Σ_p b_pc，O_c(S)=Σ_p min(b_pc,u_p(S))，则 Δ_c(S)=a_c−O_c(S)。在共同前缀 S 上，静态排序 a_x≥a_y，但 O_x−O_y>a_x−a_y 时，边际排序严格反转。要证明下一步不同，还需确定全体剩余候选的最大者；要证明最终目标不同，还需预算截断及最终成本比较。排序变化本身不够。

**PROVED：** 令 e=E/1024、d=推进量/1024，冻结模型单请求边际为

\[
\Delta_p=d[a+(b+2c)t-2ce-cd],\qquad b+2c=0.033570309.
\]

所以深度、已有覆盖和 T 都可影响排序。即使 Δ=w·r 且 w 固定，WFC 仍先看 q，不自动等价；当所有竞争候选 q 相同、单位收益相同且 tie 一致时，才可直接推出同序。

**OPEN：** B4-C 未执行独立的目标位置项消融。g003 连 r 都优先 A5，故 WFC 失败不需要借助位置项解释；同链去冗余也不是位置项独立贡献。B3 的位置权重解析例只说明可能性，不证明真实负载中该项的独立净收益。

## 4. T5：前缀树结构与条件性精确求解

### 4.1 支持集合的嵌套/互斥（CONDITIONAL，证明完整）

额外假设：所有候选和 Pending 属于同一执行配置；候选完整驻留且 eligibility 在快照固定；准入**当且仅当**候选完整 Token 串是目标输入的前缀并且 L≤T；没有额外的配对特定过滤或联合物理约束。这里的“当且仅当”不能被仅有前缀必要条件替代。

把每个 Pending 输入截到固定 T_p，在真实 Token trie 中该位置挂一个需求终端；内部节点也可挂终端。候选位于其 L_c 对应节点。一个候选覆盖的正深度需求正是其子树中的需求终端。两个 trie 节点要么祖先/后代，要么处于不同分支：前者的需求集合包含，后者不相交。故覆盖族为 laminar（允许相等及空集）。L=0 的零收益支持可视为空集；有成本平台时正收益支持还需单独处理，本轮严格单调 Phi 不存在该问题。

截断目标不可省略：只对完整输入建树而不在 T 挂终端，会错误让 L>T 的后代覆盖该请求。同 Token 前缀/位置的多个逻辑候选在本目标及纯基数约束下等价，可保留一个规范代表；这仅是数学去重，不是允许释放别名物理组件的结论。

### 4.2 深度支配为何足够保存一个祖先状态（CONDITIONAL）

在上述树结构中，同一路径上已选候选的最深者对每个子树需求弱支配其所有祖先，因为 Phi 随 G 非减。来自其他子树的选择不覆盖该需求。因此，子问题只需知道子树外最深的已选祖先 a，而不必保存整个已选集合。

仅有抽象 laminar 支持但任意收益矩阵并不充分：同一支持上的两候选可能分别更有益于不同请求，就不能用最深祖先一个标量概括。这里同时使用真实前缀树和本模型随深度单调的收益。

### 4.3 精确树形动态规划的定义（CONDITIONAL，非实现）

保留根、候选节点、需求终端和分叉节点，压缩其余单链。记压缩树节点数 N、候选节点数 n、Pending 数 m；N=O(n+m+1)，但读取原始 Token 仍需与输入总长度相应的预处理。引入不占预算、深度 0 的虚拟祖先 ⊥。令 a 为 v 的严格候选祖先之一或 ⊥，定义：

\[
D(v,a,k)=\text{在 v 子树恰选 k 个候选、外部最深已选祖先为 a 时的最小子树恢复成本}.
\]

不可能状态为 +∞，0≤k≤min(K,n)。令 P_v 是恰在 v 挂载的需求，

\[
Q_v(a)=\sum_{p\in P_v}\Phi(T_p-L_a,T_p),\qquad L_\bot=0.
\]

若子节点为 u_1,…,u_d，则不选择 v 的代价为

\[
D_{\rm skip}(v,a,k)=Q_v(a)+\min_{\sum_i k_i=k}\sum_i D(u_i,a,k_i).
\]

若 v 是候选且 k≥1，选择 v 的代价为

\[
D_{\rm take}(v,a,k)=Q_v(v)+\min_{\sum_i k_i=k-1}\sum_i D(u_i,v,k_i).
\]

D 为两者最小；非候选不允许 take。空孩子集合的卷积只有总预算 0 时为 0，否则 +∞，由此覆盖叶节点。内部需求不能由后代覆盖，故 Q_v 必须在当前节点结算，不能下推到叶子。最终答案为 min_{0≤k≤K}D(root,⊥,k)。预算可先截为 min(K,n)。零深度无收益候选可以忽略；虚拟根不计费。

### 4.4 正确性证明与复杂度（CONDITIONAL，证明完整）

对子树高度归纳。叶节点只有选/不选两种可行情况，公式穷尽并准确计算需求成本。假设各子树 D 正确。任一 v 子树可行解要么不选 v，所有孩子的外部最近祖先仍为 a；要么选 v，最近祖先统一变成 v。选入的候选按不同孩子子树唯一分配预算，且子树需求互不交叉，给定祖先后成本可加。归纳假设下，每种预算划分的最优成本由孩子 D 给出，卷积穷尽全部划分，取两种情况最小恰为整体最优。反向将最优孩子解组合也满足基数及前缀约束，故没有产生不可实现的模型解。根枚举预算得到原问题 Exact OPT。证毕。

每个节点至多 n+1 个祖先状态，至多 K+1 个预算。逐孩子进行基数卷积，每条树边对每个允许祖先最多 O(K²) 次组合。保守时间上界 O(N(n+1)K²+m(n+1))，空间 O(N(n+1)(K+1))；另计 Token trie 构建和输入读取成本。这里按固定 Phi 一次评价 O(1)、实数算术单位代价计复杂度；不是精确有理数位复杂度或实际运行时间测量。可选回溯表不改变该空间阶。

这证明该**受限问题存在多项式精确解法**，不证明当前 Greedy 最优，也不证明该状态压缩在任意 Runtime 配对过滤、非完整组件、不同大小或资源耦合下适用。本轮未实现、未测算性能、未在 B4-C 上运行 DP。

### 4.5 与现有 Runtime 的距离（OPEN）

全局删除不合格候选不会破坏树形包含；独立删除某些候选–请求边却可能破坏包含。现有安全、状态身份和兼容准入是否恰好等于完整前缀祖先关系，不能仅凭接口名、少数准入边或旧矩阵 laminar 统计证明。B4-B1 的准入记录支持限定的受控快照证据，未建立所有部署配置均为纯前缀树问题的定理。

即使某个实例通过额外检查满足树合同，也只能说明其可使用上述精确结构，不能声称已有 Runtime 自动提供该求解器。不能从一般 max-coverage 的困难性直接推断此受限前缀问题同样困难；同样不能从本节结构定理推出全部 FlowState 物理控制问题易解。

## 6. 对 Contribution 2 的影响

1. **PROVED：可保留的理论主张。** 给定正确固定的兼容关系与目标，FlowState 优化归一化单调次模恢复收益；精确 Greedy 有经典基数近似保证。可将其表述为已有理论在可执行恢复模型上的适用性，而非新次模定理。
2. **OBSERVED：可保留的机制主张。** 四个严格准入快照出现动态去冗余与覆盖数优先造成的共同目标差异，同时保留 Greedy 失败与强基线持平。它们说明机制可以影响选择质量，不说明所有负载需要全局复杂优化，不支持总体净性能优势。
3. **PROVED/CONDITIONAL：必须明确的简化边界。** 独立正支持情形可精确化简；纯前缀树和深度支配情形也存在精确树 DP。不能把所有真实前缀共享实例都描述为只能靠近似 Greedy 求解的无结构覆盖问题。Greedy 的工程动机可以是简单，但其实际控制成本优势仍需独立证据，不能在本报告推定。
4. **OPEN：位置感知独立分配收益。** 模型准确、数学排序可变与真实最终收益改善是不同命题。B4-C 没有隔离目标位置项；B3 只提供解析可能性。
5. **OPEN：Runtime 的完整闭环。** EPOCH_ADMISSIBLE、实际逐边恢复、选集安全实现、物理保留预算以及控制开销后净收益分别需要证据。本报告不扩大已有认证范围。

建议最小表述：在固定且经认证的执行兼容关系下，使用恢复成本边际统一分配；明确可分及树形结构的精确可解子类，保留 Greedy 的近似性质、四个失败条件及真实小样本的适用边界。无需在本轮修改论文、算法或新增实验。
